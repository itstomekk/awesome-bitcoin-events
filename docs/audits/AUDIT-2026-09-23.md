## Fixed in this pass

1. **Finished events still shown as “Upcoming” on the site.** Migrated records carry a frozen `maintainer.lifecycle.status: announced`, and the site trusted it. The site said 46 upcoming while the README (date-derived) said 43 — Noderunners 2026, Copa Bitcoin 2026 and Bitcoin Treasuries Unconference NYC had already ended. `src/lib/content-events.js` now re-derives past/announced from dates at build time; `cancelled` and `postponed` are kept as stored.
2. **No scheduled rebuild.** Even with date-derived status, a static site only refreshes on push. `pages.yml` now rebuilds and deploys daily (03:17 UTC).
3. **Tests only ran on Windows.** Binary names are now chosen by OS; 45/45 pass on Linux. CI now installs Python and runs `pytest` before the build.
4. **Leaflet loaded from unpkg without Subresource Integrity.** Added the official `sha256` hashes (verified against the served files).
5. **11 events without a country** (Bangkok, Wellington, Jaipur, Sofia, London, Lugano, New York City, Warsaw, Bristol, Queenstown, Fontainebleau). Added country + ISO code; README/EVENTS.md regenerated.
