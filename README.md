# Awesome Bitcoin Events [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of Bitcoin conferences, meetups, festivals and retreats around the world.

Every event links to its organizer's official page. Browse the same list with search, filters and a map on the **[website](https://itstomekk.github.io/awesome-bitcoin-events/)**. The website is built from this file.

Dates and places change. Check the official page before you book travel. Being listed is not an endorsement.

## Contributing

Add an event by editing this file. There's one line per event, under the right year and month, in date order:

```markdown
- [Event name](https://official-page.example) - Oct 12–15 · City, Country · Conference.
```

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full format. If you'd rather not edit Markdown, **[submit the event through a form](https://github.com/itstomekk/awesome-bitcoin-events/issues/new?template=event-submission.yml)**.
