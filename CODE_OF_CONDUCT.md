# Code of Conduct

## Our standard

Awesome Bitcoin Events is a public community project. Participants should be respectful, specific, and evidence-led. Disagreement about an event, source, date, or verification state is welcome; personal attacks, harassment, spam, and intimidation are not.

## Expected behavior

- Focus criticism on records, sources, and code rather than people.
- Give maintainers enough evidence to reproduce a correction.
- Respect privacy. Do not publish personal contact details, credentials, or private correspondence.
- Disclose conflicts of interest when promoting an event you organize.
- Keep issue reports and pull requests focused on one coherent change.

## Enforcement

Maintainers may edit, close, or remove contributions that violate this code, and may restrict participation when necessary to protect the community. To report a concern, open a GitHub issue without private or sensitive information, or contact the repository maintainers through the GitHub profile.
